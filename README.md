## Why This Matters

A 68.5% checkout drop-off means nearly 7 in 10 users who intend to buy 
never complete the purchase. This project quantifies exactly where and why that happens — and which segments to target first for maximum revenue recovery.

---

## 📌 Project Overview

This project analyses a 4-stage e-commerce conversion funnel — **Browse → Add to Cart → Checkout → Purchase** — to identify drop-off bottlenecks and revenue patterns across device types, regions, acquisition channels, and product categories.

**Core Business Question:**  
*Where are users dropping off in the funnel, and which segments have the highest conversion potential?*

**Dataset:** 10,000 user sessions · 21,606 events · €1,214,882 total revenue  
**Overall Conversion Rate:** 11.1% (1,107 out of 10,000 users completed purchase)  
**Critical Bottleneck:** Checkout → Purchase stage with 68.5% drop-off

## 📊 Dataset — `funnel_analysis_data.csv`

| Column | Type | Description |
|---|---|---|
| User_ID | string | Unique user identifier (USR00001–USR10000) |
| Session_ID | string | Unique session identifier |
| Event | string | Funnel stage: Browse / Add to Cart / Checkout / Purchase |
| Timestamp | datetime | Event timestamp (30-day window) |
| Device | string | Mobile / Desktop / Tablet |
| Region | string | North / South / East / West |
| Channel | string | Google Ads / Organic / Email / Social Media |
| Product_Category | string | Electronics / Fashion / Home / Beauty / Sports |
| Revenue | float | Purchase value in EUR (0 for non-purchase events) |
| Bounce_Flag | string | Yes = user did not convert · No = user purchased |

> **Note:** Device/Region/Channel are assigned per-event in the raw data. The notebook maps canonical attributes from the Browse row for accurate segment analysis.

## 📉 Funnel Results

| Stage | Users | Conversion from Browse | Drop-off from Previous | Business Action |
|---|---|---|---|---|
| Browse | 10,000 | 100.0% | — | Baseline |
| Add to Cart | 6,990 | 69.9% | 30.1% | Improve product page engagement |
| Checkout | 3,509 | 35.1% | 49.8% | Cart abandonment email within 1 hour |
| **Purchase** | **1,107** | **11.1%** | **68.5% <- Critical** | Simplify checkout — biggest ROI fix |

---

## 🔁 Session Sequence Engineering

Per-user funnel paths are engineered in Section 2B to enable journey-level analysis beyond simple stage counts.

| Path Depth | Users | % of Total |
|---|---|---|
| Browse Only | ~3,010 | ~30.1% |
| Cart Abandoner | ~3,481 | ~34.8% |
| Checkout Abandoner | ~2,402 | ~24.0% |
| **Full Converter** | **~1,107** | **~11.1%** |

**Key insight from path analysis:** Cart Abandoners (34.8%) represent the largest recoverable segment — triggered email campaigns within 1 hour of abandonment are the highest-ROI intervention.

---

## 📈 Key Findings

**Funnel Bottlenecks:**
- Browse -> Add to Cart: 30.1% drop-off — users not engaging with products
- Add to Cart -> Checkout: 49.8% drop-off — cart abandonment issue
- Checkout -> Purchase: 68.5% drop-off — highest loss point, checkout friction

**By Device:** All three devices show similar conversion rates (~11%) — no single device underperforms significantly

**By Channel:** Google Ads drives the highest revenue (EUR 317,508) followed by Email (EUR 303,078)

**By Category:** All 5 categories show comparable conversion — no single category dominates

**Revenue:** EUR 1,214,882 total · AOV ~EUR 1,097 per order

## What I'd Do With More Data

With A/B test data I'd measure the revenue impact of checkout simplification directly. With real session timestamps I'd build a time-decay model to identify the optimal window for cart abandonment email triggers.

---

## 💼 Business Recommendations

1. **Fix the Checkout Bottleneck** — 68.5% drop-off at checkout is the single biggest revenue leak. Simplify the checkout flow, reduce form fields, add guest checkout, and display trust badges prominently.

2. **Cart Abandonment Campaigns** — 3,481 users added to cart but never checked out. Implement triggered email campaigns within 1 hour of cart abandonment with a time-limited discount.

3. **Google Ads Investment** — Highest revenue channel at EUR 317,508. Increase budget allocation and test retargeting campaigns for Browse-only users.

4. **Peak Hour Promotions** — Review fig11 for peak purchase hours and schedule flash sales or push notifications during those windows to maximise conversion.
